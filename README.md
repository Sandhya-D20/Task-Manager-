# Task Manager

A personal productivity web application built with Django.

## Features

- Create weekly tasks
- Add task descriptions and custom categories
- Set task priority and deadlines
- Track task status
- Update task status
- Delete tasks
- Add daily to-do items
- Mark daily to-dos as completed
- View weekly progress

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Git & GitHub

## Running the Project

Clone the repository and navigate to the backend folder.

Create a virtual environment:

```bash
python -m venv .venv


Activate the virtual environment:

```bash
.venv\Scripts\Activate.ps1


Install Django:

```bash
python -m pip install django


Run migrations:

```bash
python manage.py migrate


Start the development server:

```bash
python manage.py runserver
